# 규칙이 아직 없는 프로그램: 구 PC 에서 확인할 것

아래 프로그램은 설정 폴더 위치와 프로젝트 확장자를 확인할 근거(제조사 문서)를 찾지 못해 규칙(`rules/*.json`)을 만들지 않았습니다.
추측으로 경로를 넣으면 엉뚱한 폴더를 옮기거나 빠뜨릴 수 있으므로, 구 PC 에서 아래 절차로 직접 확인한 뒤 규칙에 반영합니다.
(이 문서에는 특정 PC 의 값이 없습니다. 확인한 결과는 사용자 이름 부분을 `%USERPROFILE%`, `%APPDATA%` 같은 환경 변수로 바꿔 적으세요.)

대상: 3DF Zephyr, DJI Terra, ArchiOffice(LTX), GPU-Z(포터블). 현재 감지되지 않는 프로그램은 `discover` 에 "규칙 없는 프로그램"으로 나옵니다.

## 공통 확인 절차(읽기 전용)

1. 구 PC 에서 프로그램 하나의 설정 위치만 찾기. 이 명령은 읽기만 하며 파일을 바꾸지 않습니다.

   ```
   python -m pcmigrate discover --program "3DF Zephyr"
   ```

   (프로그램 이름은 설치 프로그램 목록의 표시 이름. `pcmigrate.exe` 를 쓰면 `pcmigrate discover --program "..."`.) 결과의 후보 폴더, 근거, 크기, 파일 수, `설정 파일 없음` 판정을 기록합니다. 목록에 없으면 `discover --all` 로 다시 봅니다.
2. 탐색기 주소창에 아래를 하나씩 입력해 프로그램/제조사 이름의 폴더가 있는지 봅니다(숨김 폴더이므로 `보기 > 표시 > 숨긴 항목`을 켭니다).
   - `%APPDATA%` (Roaming)
   - `%LOCALAPPDATA%` (Local)
   - `%PROGRAMDATA%`
   - `%USERPROFILE%\Documents` (문서)
   - `%USERPROFILE%` (점으로 시작하는 폴더)
3. 폴더 안에서 `.ini .json .xml .cfg .config` 같은 설정 파일, 사용자 템플릿, 프리셋이 있는지 확인합니다. `Cache`, `Logs`, `Temp` 폴더와 라이선스/로그인 파일은 옮기지 않으므로 따로 적어 둡니다.
4. 프로그램 안의 설정 메뉴(Options/Preferences)에 "설정 내보내기", "프로필", "경로" 항목이 있으면 그 화면의 경로를 확인합니다(제조사가 안내하는 이전 수단이 있으면 그쪽이 가장 안전).
5. 프로젝트 파일은 확장자만 확인합니다. 프로그램에서 프로젝트를 저장한 뒤(또는 기존 프로젝트의 속성에서) 파일 확장자와 프로젝트 폴더 구조(파일 하나인지, 폴더 + 하위 폴더인지)를 적습니다. 확장자를 `find-data` 분류표(`src/pcmigrate/find_data.py`)에 넣을지 검토합니다.
6. 제조사 도움말/지원 문서에서 같은 내용(설정 위치, 이전 방법)을 찾아 URL 과 확인 날짜를 적습니다. 문서가 없으면 확신도를 '확인 필요'로 두고 `paths` 에 넣지 않습니다.

## 프로그램별 추가로 볼 것

### 3DF Zephyr
- `discover --program "3DF Zephyr"` 로 설정/사용자 폴더 후보 확인. 라이선스(동글/로그인/라이선스 파일)가 어느 방식인지 확인(규칙에서는 복원하지 않고 경고).
- 프로젝트 확장자와 구조 확인(프로젝트 파일 + 같은 이름의 데이터 폴더가 따로 있는지). 사진측량 프로젝트는 용량이 커서 규칙이 아니라 모드 B(데이터 직접 전송) 대상입니다. 데이터 폴더가 프로젝트 파일과 떨어져 있으면 함께 옮겨야 합니다.
- 프로그램 안 Options 에서 임시/캐시 폴더 위치를 확인(제외 대상).

### DJI Terra
- `discover --program "DJI Terra"` 로 설정 폴더 후보 확인. 로그인(DJI 계정)과 라이선스는 복원하지 않고 경고.
- 프로젝트가 저장되는 폴더 위치와 확장자/구조 확인(프로젝트 폴더 통째로인지). 처리 결과(정사영상, 포인트클라우드 등)는 모드 B 대상.
- 캐시/로그 폴더가 어디인지 확인(제외 대상).

### ArchiOffice LTX
- 데이터베이스/데이터 폴더가 설치 폴더, 공유 폴더, 서버 중 어디인지 확인(설정 화면 또는 `discover --program "ArchiOffice"` 의 설치 폴더 설정 후보). 로컬 DB 를 쓰면 복사만으로 이전되지 않을 수 있어 제조사 이전 절차를 확인해야 합니다.
- 라이선스/동글 여부와 버전 호환(신 PC 에 같은 버전이 설치되는지) 확인. 구버전(2015)이 새 Windows 에서 동작하는지는 제조사에 확인합니다.
- 데이터 파일의 확장자와 백업 기능(프로그램의 백업/복원 메뉴)이 있는지 확인. 있으면 그 파일을 모드 B 로 옮기는 것이 안전합니다.

### GPU-Z(포터블)
- 설치 프로그램이 아니라 실행 파일이라 설치 목록으로 감지되지 않습니다. 설정은 보통 실행 파일 옆의 파일(예: `.ini`)이나 레지스트리일 수 있으나 확인되지 않았습니다.
- 구 PC 에서 실행 파일이 있는 폴더를 열어 같은 폴더에 설정 파일이 생기는지 확인합니다. 하드웨어 진단 도구라 새 PC 에서는 최신판을 새로 받는 것이 일반적이며, 규칙 대상이 아닐 가능성이 큽니다(실행 파일은 `.exe` 라서 이 도구가 복원하지 않습니다).

## 확인 후 규칙을 만들 때

- 기존 규칙(`rules/photoshop.json`, `rules/zwcad.json` 등)의 형식을 따르고, `notes` 에 출처 URL 과 확신도('공식 문서 확인' / '일반 지식·확인 필요')를 적습니다.
- 근거가 있는 경로만 `paths` 에 넣고, 캐시/로그/임시/라이선스/로그인 파일은 `exclude` 와 `manual_warnings` 로 다룹니다.
- `tests/test_rules_stage49.py` 를 본떠 감지 이름의 오탐 테스트와 가짜 폴더 수집 테스트를 추가합니다.
- ZWCAD 도 같은 방식으로 확인이 필요합니다: `%APPDATA%` 아래 ZWCAD 폴더의 하위 구조(사용자 지원 파일, 메뉴, 플롯 스타일, 템플릿 위치)를 `discover --program "ZWCAD"` 로 확인.
