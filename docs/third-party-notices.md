# 서드파티 고지 (알려진 범위)

이 프로젝트의 소스는 외부 Python 패키지에 의존하지 않습니다(`pyproject.toml` 의 `dependencies` 가 비어 있음). 다만 **exe 묶음(`pcmigrate-win.zip`)** 에는 아래 구성요소가 함께 들어갑니다. 이 프로젝트 자체의 권리는 [LICENSE](../LICENSE) 가 정하고, 아래 구성요소는 각자의 라이선스를 따릅니다.

> 이 문서는 **알려진 범위의 기록**이며 법률 검토를 거친 목록이 아닙니다. 확인하지 못한 항목은 '확인 필요'로 적었습니다. 외부에 배포하기 전에 소유자가 정확한 구성과 라이선스 전문을 확인하세요.

| 구성요소 | 쓰임 | 라이선스(알려진 것) | 상태 |
|---|---|---|---|
| Python (CPython 3.13 실행기와 표준 라이브러리) | exe 안의 실행 환경 | Python Software Foundation License | 라이선스 전문(`LICENSE.txt` 등)을 exe 묶음에 넣었는지는 **확인 필요** |
| Tcl/Tk 8.6 (tkinter 의 기반) | GUI 화면 | Tcl/Tk License (BSD 계열의 허용적 라이선스) | exe 묶음에 Tcl/Tk 런타임 파일이 들어감. 고지문 포함 여부는 **확인 필요** |
| PyInstaller 6.16.0 (`packaging/build_exe.py` 가 임시 가상환경에서 사용) | exe 로 묶는 도구와 부트로더 | GPL-2.0 이상 + 묶은 프로그램에는 GPL 이 적용되지 않게 하는 예외 조항(부트로더 예외) | 예외 조항의 정확한 문구와 버전별 적용은 **확인 필요** |
| Python 설치본에 딸린 DLL/모듈(OpenSSL, zlib, libffi, expat, SQLite, bzip2, xz 등) | 표준 라이브러리 일부가 사용 | 각 프로젝트의 허용적 라이선스로 알려져 있음 | 실제로 exe 묶음에 들어가는 목록은 빌드마다 PyInstaller 가 정하므로 **확인 필요** |

## 해야 할 확인(릴리스 전)
1. 빌드한 exe 묶음의 폴더 안에 실제로 들어간 DLL/데이터 목록을 뽑아 위 표와 대조합니다.
2. Python, Tcl/Tk, 그리고 3번 항목의 구성요소 라이선스 전문을 exe 묶음 안에(예: `licenses` 폴더) 함께 넣을지 소유자가 정합니다. 현재 빌드 스크립트는 이를 자동으로 넣지 않습니다.
3. PyInstaller 의 예외 조항 문구를 공식 저장소의 해당 버전 `COPYING.txt` 에서 직접 확인합니다.

## 배포 범위
exe 묶음과 이 문서의 내용은 소유자가 허락한 사용자에게만 제공됩니다([README](../README.md) 의 내려받기 절 참고).
