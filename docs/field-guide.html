PC 이전 현장 가이드

구 PC에서 새 Windows 11 PC로 옮길 때 현장에서 펼쳐 보는 한 장입니다. 체크 표시는 이 기기의 이 브라우저에만 저장됩니다. 이 파일은 인터넷 없이 열립니다(링크는 인터넷이 있을 때만 열림).

확인됨공식 문서를 열어 확인 요약·일반2차 요약이나 일반 지식 미확인제조사에 직접 확인 도구이 도구가 해 줌 직접사람이 직접
준비물 순서 방식 선택 랜선 준비 외장 준비 도구 명령 막힐 때 지우기 전 링크 확인할 것
이 도구가 하지 않는 것. 프로그램 설치, 라이선스 복원, 브라우저 비밀번호와 쿠키, 카카오톡, 공인인증서 이전은 되지 않습니다. 구 PC의 파일은 지우지 않습니다. 새 PC에서 확인이 끝나기 전에는 구 PC를 지우거나 포맷하지 마세요.

2. 전체 순서

구 PC에서

  1. 1
    직접모든 프로그램 종료(Chrome 등 실행 중인 프로그램은 닫고 내보내기), 전원 연결열려 있는 파일은 복사와 검사에 실패합니다. 특히 Chrome/Edge가 실행 중이면 프로필 파일이 잠겨 설정 패키지에서 제외됩니다.
  2. 2
    도구프로그램 조사와 해야 할 일 목록 저장① 쓰던 PC에서 준비하기의 1~3단계. 목록 파일에 이 PC의 설치 목록이 들어 있으니 공유하지 마세요.
  3. 3
    도구직접자동 목록에 없는 프로그램 확인과 선택자동으로 포함되지 않습니다. "보이는 항목 전체 선택/해제" 단추로 한꺼번에 고를 수 있으나 비밀 정보 경고 항목은 전체 선택에서 빠지니 신중하게 직접 고르세요.
  4. 4
    도구설정 묶음 파일(.zip) 내보내기라이선스는 들어가지 않습니다.
  5. 5
    도구직접② 내 파일 옮기기에서 데이터 복사 방식 선택(외장 또는 랜선)과 복사구 PC는 보내는 쪽입니다. ①에서 만든 설정 묶음도 '설정 묶음 함께 보내기'로 같이 보낼 수 있습니다. 미리보기 후 복사. 끝나면 결과가 "실패 0"인지 확인합니다.
  6. 6
    직접검증이 끝날 때까지 구 PC를 지우거나 포맷하지 않기

새 PC에서

  1. 1
    직접Windows 업데이트와 장치 드라이버
  2. 2
    도구직접필요한 프로그램을 새로 설치하고 라이선스 인증동글 드라이버 포함. 가능하면 각 프로그램을 한 번 실행했다가 종료하세요. 새 PC 마법사의 "프로그램 설치 확인"이 이미 설치된 것, 안 깔린 것, 애매한 것을 나눠 보여 줍니다. 설치 명령은 복사만 해 주니 직접 실행한 뒤 "다시 확인"을 누르세요.
  3. 3
    도구② 내 파일 옮기기의 받는 쪽(새 PC)에서 데이터 복사와 검사랜선이면 새 PC에서 "검사 시작"으로 해시 목록과 비교합니다.
  4. 4
    도구③ 새 PC에서 설치하고 가져오기에서 모든 프로그램을 종료하고 설정 묶음 파일 미리보기를 확인한 뒤 복원덮어쓴 파일은 .bak으로 남습니다.
  5. 5
    직접각 프로그램을 열어 설정, 템플릿, 글꼴, 플로터, 참조 경로 점검, 라이선스 상태 확인
  6. 6
    도구직접폴더 위치(드라이브 문자)가 구 PC와 같은지 확인도면의 외부 참조(XREF)와 데이터 단축은 절대 경로를 쓸 수 있습니다. 위치가 다르면 도구가 경고하지만 도면에서 참조가 이어지는지는 직접 열어 봐야 합니다.

4. 랜선 준비 일반 순서, 환경에 따라 다름

같은 공유기나 스위치에 두 PC를 유선으로 연결하는 쪽이 가장 쉽습니다. 공유기가 없으면 랜선 하나로 두 PC를 직접 잇고 양쪽에 고정 IP를 정합니다(크로스 케이블은 필요 없습니다).

① 직결일 때 고정 IP (게이트웨이는 비움)

새 PC, 관리자 PowerShell (이름 "Ethernet"은 Get-NetAdapter로 확인)
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.50.2 -PrefixLength 24
구 PC
New-NetIPAddress -InterfaceAlias "Ethernet" -IPAddress 192.168.50.1 -PrefixLength 24

② 네트워크 프로필을 개인으로 확인됨

공용(Public)이면 PC가 숨겨지고 파일 공유에 쓸 수 없습니다.

Set-NetConnectionProfile -InterfaceAlias "Ethernet" -NetworkCategory Private

③ 새 PC에 공유 폴더 만들기 확인됨

먼저 비밀번호가 있는 로컬 계정을 하나 만드세요. 비밀번호가 없는 로컬 계정은 네트워크 로그온이 안 됩니다. 공유 이름은 80자까지입니다.

관리자 PowerShell, 계정 이름은 실제 값으로
New-SmbShare -Name Migrate -Path D:\Migrate -ChangeAccess "PC이름\접속계정"
"파일 및 프린터 공유" 방화벽 규칙 이름은 한글 Windows에서 다를 수 있습니다
Get-NetFirewallRule | Select DisplayGroup -Unique
Enable-NetFirewallRule -DisplayGroup "File and Printer Sharing"

④ 구 PC에서 접속 시험

Test-NetConnection -ComputerName 192.168.50.2 -Port 445
net use Z: \\192.168.50.2\Migrate /user:PC이름\접속계정 *

탐색기 주소창에 \\192.168.50.2\Migrate를 열어 보고, 파일을 하나 만들었다 지워서 쓰기가 되는지 확인하세요. 접속이 꼬이면 net use * /delete로 기존 연결을 끊고 다시 시도합니다. net use는 동작하지만 현재 Microsoft Learn에는 공식 문서가 없고 보관본뿐입니다.

계속 접속이 안 될 때 (시스템 오류 67 "네트워크 이름을 찾을 수 없습니다", 1222 "네트워크를 사용할 수 없습니다" 등). 위 ①~③과 포트 445 확인을 한 번씩 했는데도 같은 오류가 나면 설정에 오래 매달리지 말고 외장 SSD/HDD 방식으로 바꾸세요(5장). 회사 보안 소프트웨어나 네트워크 정책이 공유 폴더 접속을 막는 경우는 현장에서 고치기 어렵습니다. 외장 방식은 네트워크 없이 같은 해시 검증과 이어받기를 그대로 씁니다.

⑤ 링크 속도

Get-NetAdapter | ft Name,LinkSpeed,Status

1000/1000이어야 합니다. 100Mbps로 나오면 케이블(Cat5e 이상)과 어댑터를 바꿔 보세요. 100Mbps면 1TB에 하루 이상 걸립니다.

⑥ 받는 새 PC의 절전을 끄세요

이 도구는 도구를 실행하는 PC(구 PC)의 절전만 막습니다. 받는 PC는 직접 전원을 연결하고 절전을 꺼야 공유가 끊기지 않습니다.

관리자, 분 단위(0은 안 함, powercfg /? 도움말 기준)
powercfg /change standby-timeout-ac 0
powercfg /change monitor-timeout-ac 0

어댑터 전원 절약은 장치 관리자의 네트워크 어댑터 속성에서 "전원 관리" 탭의 "전원을 절약하기 위해 이 장치를 끌 수 있음"을 해제하는 것이 확실합니다. 이전이 끝나면 절전 설정을 원래대로 돌리세요.

Windows 11 24H2 Pro 이상은 SMB 서명을 기본으로 요구하고 Home은 요구하지 않습니다. 서명을 못 하는 NAS나 게스트 접속은 실패할 수 있습니다. Microsoft는 서명을 끄는 우회를 권장하지 않습니다. 조사원 보고

5. 외장 드라이브 준비
  • NTFS로 포맷하세요. FAT32는 파일당 4GiB 제한이고 NTFS와 exFAT는 사실상 제한이 없습니다. ACL과 소유자는 NTFS만 지원합니다. 확인됨
  • 이 도구는 대상이 FAT32이고 4GB 초과 파일이 있으면 복사 전에 막습니다. 포맷이 어려우면 transfer에 --split-large를 붙여 큰 파일을 조각(이름.pcm001, .pcm002 …)으로 나눠 저장하고, 새 PC에서 join으로 합칩니다.
  • 포맷은 데이터를 모두 지웁니다. 포맷 명령의 -WhatIf는 미리보기로 동작하지 않는다고 문서에 있습니다. 드라이브 문자만 보고 지우지 말고 크기와 모델을 먼저 확인하세요.
포맷 전에 먼저 (관리자 PowerShell)
Get-Disk
Get-Volume
E:는 예시입니다. 전체 삭제됩니다
Format-Volume -DriveLetter E -FileSystem NTFS -NewFileSystemLabel MIGRATE
  • USB 3.x(파란색 SuperSpeed 포트)에 꽂으세요. USB 2.0은 실사용 약 35~40MB/s입니다. 일반
  • BitLocker: "장치 암호화"는 외장 USB를 암호화하지 않습니다. 암호화된 드라이브는 새 PC에서 암호나 복구 키가 필요하고, Microsoft는 잃어버린 키를 복구해 주지 못합니다. 확인됨
  • 분리할 때는 "하드웨어 안전하게 제거"를 쓰고, 새 PC에서 드라이브 문자가 바뀌면 도구가 경고합니다.

6. 도구 명령 (명령줄을 쓸 때)

화면(pcmigrate-gui.exe)을 쓰면 아래 명령은 필요 없습니다. 명령줄은 pcmigrate 폴더에서 pcmigrate.exe로 실행합니다. 옵션은 pcmigrate.exe <명령> --help로 확인하세요.

조사와 체크리스트 (구 PC, 읽기만)

pcmigrate.exe scan
pcmigrate.exe checklist --format md --output C:\이전기록\체크리스트.md
pcmigrate.exe discover --output C:\이전기록\후보.md --output-selection C:\이전기록\선택.json
pcmigrate.exe discover --program "프로그램 이름" --output-selection C:\이전기록\선택.json

결과 파일에는 이 PC의 설치 목록이 들어 있으니 공유하거나 커밋하지 마세요. 저장소 폴더가 아닌 곳에 두세요.

discover --program (화면의 "이 프로그램 설정 찾기")은 프로그램 하나의 설정 위치만 이름으로 찾습니다. 전체 탐색과 달리 캐시, 로그, 임시 폴더도 찾아 "임시 저장물일 수 있음", "로그", "라이선스" 배지를 붙여 보여 주며 자동으로 선택하지 않습니다. 라이선스는 발견만 표시하고 이 도구는 옮기지 않습니다. 내보내기는 직접 고른 폴더 안의 다시 만들어지는 임시 저장물 폴더(Cache, GPUCache, node_modules 등)를 기본으로 빼고 이름, 파일 수, 용량을 기록합니다(export --include-caches 또는 화면의 고급 옵션 "캐시 폴더도 포함"으로 포함). 내보낸 뒤와 복원 미리보기에는 프로그램별 설정 확인표(프로그램, 옮기는 설정, 상태, 담긴 파일 수)가 나옵니다.

일부 프로그램은 설정을 설치 폴더(Program Files 등)에 둡니다. 설정 찾기 결과의 "설치 폴더 설정" 배지 항목은 직접 체크해야 담기고, 신 PC에서는 기본으로 복원하지 않습니다. 복원하려면 같은 버전의 프로그램을 먼저 설치하고 관리자 권한으로 실행한 뒤, 복원 미리보기에서 "설치 폴더 설정도 복원"을 체크하세요(명령줄은 import --allow-install-dir). 설정 형식 파일만 복원하고 기존 파일은 .bak으로 남깁니다. 프로그램/폴더를 찾았는데 설정 형식 파일이 하나도 없으면 "설정 파일로 보이는 파일이 없습니다(폴더 용량은 설정 형식이 아닌 파일입니다. 필요하면 폴더 전체 담기)"로 알려 줍니다. 구 PC 2단계 표의 설정 파일 열에는 회색 "없음"으로 나오며, 체크하면 담기는 파일이 0개라는 안내가 뜹니다(명령줄은 --extra-mode all). 프로그램별 복원 선택(--only/--skip)에서는 설치 폴더 설정을 install(전부) 또는 install:<프로그램 이름>으로 고르고, undo-import도 설치 폴더 복원을 되돌립니다(권한이 없으면 관리자 권한으로 다시 실행해 주세요).

카카오톡 대화, 금융보안·키보드 보안 모듈, 인증서, 백신, 그래픽 드라이버, Office, Adobe CC 처럼 폴더를 복사해서는 옮길 수 없는 프로그램은 구 PC 2단계 표에서 일반 후보와 분리되어 표 아래의 접힌 구역 "자체 이전이 필요한 프로그램 N개"에 모입니다. 줄을 고르면 이유와 대신 할 일이 나오고, 체크는 할 수 있지만(막지 않음) 안내 창이 뜨며, "전체 선택"은 이 구역을 선택하지 않습니다. 이 목록은 selftransfer/*.json 에 있어 파일을 추가하면 코드 수정 없이 늘릴 수 있습니다.

설정 패키지

구 PC: 내보내기 (선택 파일의 include 가 true 인 항목만 추가됨)
pcmigrate.exe export --output E:\이전\설정.zip --extra C:\이전기록\선택.json
새 PC: 미리보기 먼저, 확인 후에만 --yes
pcmigrate.exe import E:\이전\설정.zip --dry-run
pcmigrate.exe import E:\이전\설정.zip --yes

--yes 없이 실행하면 아무것도 쓰지 않고 미리보기만 보여 준 뒤 종료 코드 2로 끝납니다. 규칙 없이 선택한 항목을 복원하려면 --allow-extra가 필요합니다.

  • 내보내기 결과의 "읽지 못해 제외된 파일 N개": 실행 중인 프로그램(예: Chrome의 LOCK 파일)이 잠근 파일은 읽을 수 없어 패키지에서 빠지고, 결과에 개수와 예시 경로 5개가 나옵니다. 오류가 아니라 안내이며 패키지는 검증을 통과한 상태입니다. 해당 프로그램을 닫고 다시 내보내면 줄어듭니다. 전체를 다시 만들 필요는 없습니다: 화면의 "이 파일들만 다시 담기" 버튼(또는 pcmigrate export --output 묶음.zip --retry-failed)을 누르면 읽지 못한 파일만 다시 읽어 이미 만든 묶음에 추가하고, 이전 묶음은 .bak 으로 남깁니다. 실제로 쓸모없는 잠금 파일(LOCK, SingletonLock 등)은 늘 제외됩니다.
  • 목록 밖 프로그램은 설정 파일만 담습니다(허용 방식): 규칙이 없는 프로그램의 폴더(--extra)는 기본으로 설정 형식 파일(.ini .json .xml .cfg .yaml .toml, 건축 CAD 사용자 정의 .pgp .cuix .dwt .ctb .rte 등)만 담고, 파일 하나 32MB, 폴더 하나 256MB 또는 5000개를 넘는 것과 나머지(.dat .bin .log .txt, 실행 파일, 라이선스, 캐시)는 빼고 개수와 용량만 기록합니다. 결과에 "허용 방식으로 담은 파일(확장자별 개수)"과 "제외된 파일(설정 형식이 아님) N개, 용량"이 나옵니다. .reg 는 레지스트리를 바꾸는 실행성 파일이라 담지 않습니다. 확장자 없는 설정 파일(예: Preferences)이 빠지면 export --extra-mode all(예전 방식: 폴더 전체에서 캐시만 제외)로 내보내세요. 규칙이 있는 프로그램은 이 옵션과 무관합니다.
  • 무엇이 빠졌는지 보기: 허용 방식에서 빠진 파일은 폴더마다 제외 N개, 용량(사유별 개수) 한 줄과 큰 파일 예시 최대 5개(이름·크기·사유)로 설정 확인표에 나옵니다(GUI는 줄을 누르거나 자세히 ▸). 전체 목록은 만들지 않고, 사유는 이름/확장자로 짐작한 것입니다. 확장자 없음(설정일 수 있음) 이 있으면 노란 안내가 나오니 필요할 때 폴더 전체 담기로 다시 내보내세요.
  • 프로그램별로 골라 복원/되돌리기: 새 PC 에서 일부 프로그램만 복원하거나 뺄 수 있습니다: pcmigrate import 설정.zip --dry-run --only revit,autocad 또는 --skip 규칙id(미리보기에 프로그램별 파일 수, 새로 만듦, 덮어씀 표가 나옵니다. 규칙 없는 항목은 extra:appdata/폴더이름). 뺀 프로그램은 아무것도 쓰지 않고 "선택에서 제외됨"으로 기록합니다. 복원하면 복원 기록이 %LOCALAPPDATA%\pcmigrate\import-records 에 남고, 새 PC 에서 설정이 맞지 않아 오류가 나는 프로그램은 pcmigrate undo-import --only 규칙id --dry-run 으로 확인한 뒤 --yes 로 되돌립니다(복원이 만든 .bak 을 원래 이름으로). .bak 이 없거나 바뀌었거나 복원 뒤에 직접 고친 파일은 되돌리지 않고 이유를 알려 줍니다. 복원 때 새로 만든 파일은 지우지 않으며(--move-new 면 .removed 로 옮김) 개수만 알려 줍니다.
  • 진행 표시: 파일이 많으면 export와 import --yes는 몇 분 걸립니다. 10초마다 [진행] 줄이 나옵니다. import는 시작할 때 패키지 전체를 먼저 검사하므로 그동안은 줄이 없을 수 있습니다. 화면(GUI)에서는 현황 카드로 보입니다.
  • 내보내기가 중간에 끊겨도 같은 저장 위치로 다시 하면 이어서 합니다: 내보내는 동안에는 저장 위치 옆에 설정.zip.part(만드는 중인 파일)와 설정.zip.part.journal(진행 기록)이 생기고, 다 만들어 검사를 통과해야 설정.zip 이라는 이름이 됩니다. 그래서 설정.zip 이 보이면 완성본입니다(.part 는 가져오기가 거부합니다). 오류, 취소, 정전으로 끊긴 뒤 같은 명령(또는 화면의 같은 저장 위치)으로 다시 하면 마지막 저장점(256MB 또는 60초마다)까지는 다시 만들지 않고 이어서 합니다. 선택한 프로그램이나 압축 설정이 달라졌거나 기록이 깨졌으면 이유를 알려 주고 처음부터 합니다. 처음부터 다시 하고 싶으면 명령에 --no-resume을 붙이거나 화면의 "처음부터 다시 만들기"를 체크하세요(임시 파일만 지우고 완성본은 건드리지 않습니다). 파일 하나가 매우 크면 그 파일은 끊긴 지점에서가 아니라 처음부터 다시 담습니다.
  • 압축 생략(--compress): 기본(auto)은 사진, 영상, zip, pdf 처럼 이미 압축된 파일은 압축하지 않아 더 빨리 끝납니다. always 는 모두 압축, never 는 모두 압축 없이 담습니다. 가져오기는 어느 쪽이든 똑같이 처리합니다.
  • 규칙 폴더 오류: "규칙 폴더를 찾을 수 없습니다" 또는 "규칙 파일이 하나도 없습니다"가 나오면 exe 옆 _internal\rules 폴더가 지워진 것입니다. 이 상태로는 아무 프로그램도 감지하지 못하므로 도구가 종료 코드 1로 멈춥니다. 다시 내려받아 압축을 풀어 주세요.

대용량 복사

GUI 의 ② 내 파일 옮기기(예전 이름: 대용량 복사)는 4단계(찾기 → 방법 → 연결·복사 → 결과)입니다. 내 파일 찾기(find-data 와 같은 기능, 읽기만)로 폴더를 찾아 직접 체크하고, 방법을 두 PC를 바로 연결(추천, pcmigrate receive/send 와 같은 기능) · 외장 드라이브 · 공유 폴더(고급) 중에서 고릅니다. 바로 연결은 새 PC에서 '받는 쪽'을 먼저 열어 6자리 코드를 확인하고 구 PC에서 '보내는 쪽'으로 연결하며, 내용은 암호화되지 않으니 사설 네트워크에서만 쓰세요. 아래 명령은 같은 일을 터미널에서 하는 방법입니다.

목록만 확인 (아무것도 쓰지 않음)
pcmigrate.exe transfer D:\프로젝트 E:\이전\프로젝트 --dry-run
외장으로 복사 (같은 PC 안의 두 디스크는 복사 후 바로 검사)
pcmigrate.exe transfer D:\프로젝트 E:\이전\프로젝트 --report C:\이전기록\복사결과.json
랜선: 원본 해시 목록을 만들며 복사, 대상 검사는 새 PC로 미룸
pcmigrate.exe transfer D:\프로젝트 \\192.168.50.2\Migrate\프로젝트 --manifest-out C:\이전기록\목록.jsonl
새 PC: 해시 목록과 로컬 폴더 비교 (읽기만, 결과 파일은 검사할 폴더 밖에)
pcmigrate.exe verify --manifest C:\이전기록\목록.jsonl --target D:\Migrate\프로젝트 --report C:\이전기록\검사결과.json
중단됐거나 일부 실패했을 때: 같은 명령을 다시 실행하면 이어받고, 실패한 것만 다시
pcmigrate.exe transfer D:\프로젝트 E:\이전\프로젝트 --retry-failed
FAT32 외장에 4GB 넘는 파일이 있을 때: 조각으로 나눠 복사 (--split-large)
pcmigrate.exe transfer D:\프로젝트 E:\이전\프로젝트 --split-large --manifest-out C:\이전기록\목록.jsonl
새 PC: 나눠 저장된 조각을 NTFS 드라이브에서 원래 파일로 합치기 (조각은 지우지 않고, 해시 목록과 대조)
pcmigrate.exe join E:\이전\프로젝트 --output D:\Migrate\프로젝트 --manifest C:\이전기록\목록.jsonl
구 PC: 옮길 파일을 도구가 찾아 목록으로 보기 (읽기만, 아무것도 선택하지 않음)
pcmigrate.exe find-data --output-selection C:\이전기록\선택.json
선택.json 에서 옮길 폴더의 include 를 true 로 바꾼 뒤, 여러 폴더를 한 번에 복사 (대상 아래 D\폴더 구조 그대로)
pcmigrate.exe transfer --from-selection C:\이전기록\선택.json E:\이전 --exclude-junk --manifest-out C:\이전기록\목록.jsonl

--exclude-junk 는 Thumbs.db, desktop.ini, ~$ Office 잠금, *.tmp, CAD 잠금(*.dwl 등)을 복사하지 않습니다(기본은 제외 안 함). *.bak 와 Revit 백업 사본은 기본으로 복사하며, --exclude-backup-copies 를 더하면 Revit 백업 사본도 뺍니다. find-data 는 Windows, Program Files, AppData, 휴지통을 자동으로 뺍니다. OneDrive 클라우드 전용 파일은 내려받지 않고 개수만 따로 셉니다.

원본을 건드리는 robocopy 옵션(/MIR, /PURGE, /MOV)은 이 도구가 쓰지 않습니다. 복사가 끝나면 대상 폴더에 .pcmigrate-state.json과 로그 파일이 남습니다. 외장 2단계(--use-manifest)와 랜선 1단계(--manifest-out)는 화면의 단계 안내를 따르는 편이 안전합니다.

이 도구의 exe는 서명이 없습니다. 처음 실행하면 "Windows의 PC 보호" 창이 뜰 수 있습니다. 받은 빌드와 함께 전달받은 SHA-256 값이 아래 명령 결과와 같은지 확인한 뒤 "추가 정보, 실행"을 누르세요. 
certutil -hashfile pcmigrate-gui.exe SHA256
Get-FileHash .\pcmigrate-gui.exe -Algorithm SHA256

두 PC에서 바로 연결 (LAN 직접 전송, 공유 폴더 설정 없이)

공유 폴더(SMB)는 계정, 방화벽, 서비스 설정에 막혀 오류 67/1222 로 자주 실패합니다. 대신 두 PC 에서 도구를 켜고 6자리 코드로 연결하면 도구가 TCP 로 직접 보냅니다(같은 공유기/스위치 또는 랜선 직결 모두 가능).

새 PC: 받기 시작 (접속 주소와 6자리 코드가 표시됩니다. 받는 폴더는 시작할 때 지정, 기본은 바탕화면 아래 새 폴더)
pcmigrate.exe receive --dest D:\Migrate
구 PC: 같은 네트워크의 새 PC 를 자동으로 찾아 보내기 (자동 검색이 안 되면 "자동" 대신 새 PC 에 표시된 주소를 적습니다. 원본은 읽기만 합니다)
pcmigrate.exe send 자동 --code 123456 --from-selection C:\이전기록\선택.json --exclude-junk
연결이 안 될 때: 원인을 한 줄로 진단 (포트 열림, 서브넷, 코드, 방화벽 가능성. 아무것도 바꾸지 않습니다)
pcmigrate.exe send 192.168.0.12:47830 --diagnose --code 123456

순서: ① 두 PC 를 같은 공유기/스위치에 유선으로 연결하거나 랜선으로 직결합니다. ② 새 PC 에서 pcmigrate receive 를 실행하고 화면의 주소와 코드를 확인합니다. ③ 구 PC 에서 pcmigrate send 를 실행합니다. ④ 끝나면 양쪽에 정확함/불일치/누락 집계가 나오고, 새 PC 의 받은 폴더에 해시 목록(.pcmigrate-manifest.jsonl)이 남아 pcmigrate verify 로 다시 검사할 수 있습니다.

사설 LAN(집/사무실 공유기 안, 랜선 직결)에서만 쓰세요. 이 연결은 암호화하지 않습니다. 코드로 서로 확인하고 모든 데이터의 변조를 검사하지만(HMAC), 같은 네트워크의 제3자가 패킷을 엿보면 내용이 보일 수 있습니다. 공인(인터넷) 주소이면 경고하고 명시적으로 허용(--allow-public)해야만 씁니다. 코드는 10분 안에 한 번 짝지어야 하고 5번 틀리면 잠깁니다.

방화벽: 도구는 방화벽을 바꾸지 않습니다. 새 PC 에서 처음 실행하면 Windows 방화벽 창이 뜰 수 있으니 "개인 네트워크"만 허용하세요(공용 네트워크는 허용하지 않습니다). 연결이 안 되면 --diagnose 가 "방화벽이 막았거나 네트워크 프로필이 공용" 같은 가능성을 알려 줍니다.

랜선 직결 주소 자동 맞추기: 직결했는데 연결이 안 될 때(서브넷이 다를 때) 받기/보내기 화면의 '이 PC 이더넷 주소 자동 맞추기'를 열거나 pcmigrate lan-setup --role receiver(또는 sender)를 쓰세요. 기본은 미리보기이고 --yes 를 붙여야 적용합니다. 두 PC 의 이더넷 어댑터를 같은 대역의 고정 주소(기본 10.254.250.0/24, 보내는 쪽 .1, 받는 쪽 .2)로 임시로 바꾸고, 끝나면 원래대로 되돌립니다(DNS 와 게이트웨이는 바꾸지 않습니다). 관리자 권한 확인창이 뜹니다. 인터넷에 연결된 어댑터는 건드리지 마세요(기본으로 제외하며, 바꾸면 인터넷이 끊길 수 있습니다). 중간에 프로그램이 꺼졌다면 pcmigrate lan-setup --restore --yes 로 원래대로 되돌립니다. 아직 실제 PC 두 대에서 충분히 확인하지 못한 기능이므로, 처음에는 업무에 쓰는 PC 가 아닌 환경에서 먼저 시험해 주세요.

SMB 보다 쉬운 이유: Windows 계정/공유/서비스 설정이 필요 없고, 도구가 파일 단위로 해시를 검증하며(원본을 읽어 계산한 SHA-256 과 받으며 계산한 값을 대조), 끊겨도 같은 코드로 다시 실행하면 이어받습니다. 한계: 암호화가 없고, 한 번에 송신 PC 한 대만 받으며, 같은 서브넷(또는 랜선 직결)이어야 하고, 작은 파일이 아주 많으면 파일마다 확인하므로 느릴 수 있습니다. FAT32 드라이브의 4GB 넘는 파일(--split-large)은 이 방식에서 지원하지 않으니 NTFS/exFAT 폴더에 받으세요.

7. 막혔을 때
증상확인하고 고칠 것
복사가 멈춘 것처럼 보임잠긴 파일(열려 있는 도면, 프로그램)일 수 있습니다. robocopy의 재시도 기본값은 100만 회, 대기 30초입니다. 이 도구는 3회와 5초로 줄여 쓰지만, 먼저 모든 프로그램을 종료하세요. 닫은 뒤 "실패한 것만 다시 시도".
종료 코드가 1 또는 3실패가 아닙니다. robocopy는 8 이상일 때만 실패입니다. 확인됨
공유 폴더에 접속이 안 됨비밀번호 없는 계정인지, 네트워크 프로필이 공용인지, 방화벽의 파일 및 프린터 공유가 켜졌는지, 두 PC의 IP 대역이 같은지, ping과 포트 445를 확인하세요. 이미 다른 계정으로 연결돼 있으면 net use * /delete.
속도가 너무 느림USB 2.0 포트(실사용 약 35~40MB/s 이하)이거나 링크 속도가 100Mbps일 수 있습니다. 케이블과 포트를 바꿔 보세요. 느린 HDD/USB는 --workers 1 --copy-threads 1이 나을 수 있습니다.
4GB 넘는 파일이 복사 안 됨대상이 FAT32입니다. NTFS로 포맷하거나 다른 드라이브를 쓰세요. 포맷이 어려우면 --split-large로 조각을 나눠 저장하고 새 PC에서 join으로 합치세요.
"경로가 너무 깁니다"260자 제한입니다. 이 도구는 읽기와 검사에 긴 경로 접두를 쓰지만, 그래도 읽지 못하면 폴더를 짧은 경로로 옮기세요. 확인됨
OneDrive 파일이 건너뛰어짐클라우드 전용 파일은 기본으로 건너뛰고 cloud_only로 기록됩니다. 복사 전에 폴더를 우클릭해 "이 디바이스에 항상 유지"로 내려받은 뒤 복사하거나 --include-cloud를 쓰세요(대량 다운로드가 생깁니다). 실제 OneDrive PC에서의 동작은 아직 시험하지 못했습니다.
드라이브 문자가 바뀜도면의 외부 참조가 끊길 수 있습니다. 디스크 관리에서 "드라이브 문자 및 경로 변경"으로 구 PC와 맞추세요. C:는 바꾸지 마세요.
대상에 .bak 파일이 생김대상 폴더에 같은 이름의 다른 파일이 이미 있어서, 덮어쓰기 전에 기존 파일을 이름.bak으로 옮겨 둔 것입니다(내용은 그대로). 필요 없으면 확인 후 지우세요. 복사 전 미리보기가 몇 개인지 알려 줍니다.
검사에서 "내용 다름"복사 도중 파일이 바뀌었거나 복사본이 손상됐을 수 있습니다. 프로그램을 닫고 --strict로 다시 실행하면 어긋난 파일만 원본에서 다시 복사하고 기존 사본은 .bak로 남깁니다.
예상하지 못한 오류가 났다고 나옴오류 내용이 %LOCALAPPDATA%\pcmigrate\logs\errors-날짜.log에 기록됩니다(쓸 수 없으면 %TEMP%\pcmigrate-logs). 명령줄에서 pcmigrate.exe logs는 로그 폴더와 최근 오류 요약을, pcmigrate.exe logs --open은 탐색기로 폴더를 엽니다. 화면에서는 오류 대화상자의 "로그 폴더 열기"와 "오류 내용 복사" 버튼을 쓰세요. 로그에는 파일 경로가 들어 있으니 보내기 전에 확인하세요.
공유 폴더 접속 오류 67 또는 12224장 ④의 안내를 확인해도 계속되면 외장 SSD/HDD 방식으로 바꾸세요(5장).
exe가 안 열림SmartScreen 창에서 "추가 정보, 실행". 회사 백신이 막으면 폴더를 예외로 등록하거나 담당자에게 허용을 요청하세요. _internal 폴더가 같이 있는지 확인하세요.
중지를 눌렀는데 바로 멈추지 않음작업 중에는 아래 막대에 빨간 "중지" 버튼이 항상 있습니다. 누르면 "중지하는 중…"으로 바뀌고 다시 누를 수 없습니다. 15초가 지나도 작업이 끝나지 않으면 "아직 멈추지 않았습니다" 안내와 "지금 강제로 멈추기" 버튼이 나옵니다. 누르면 화면은 정상으로 돌아오고, 만들던 임시 파일은 이어받기가 가능한 상태로 남습니다(원본은 읽기만 했으므로 그대로입니다). 파일을 쓰는 새 작업은 옛 작업이 완전히 끝날 때까지 잠시 막힐 수 있습니다.
복원한 설정을 프로그램별로 되돌리고 싶음새 PC 복원 결과 화면의 프로그램별 되돌리기 버튼을 쓰세요. 미리보기를 보고 확인한 뒤에만, 덮어쓴 파일을 복원 전 백업 파일(.bak)로 되돌립니다. 새로 생긴 파일은 지우지 않습니다. 복원 기록이 없으면 버튼이 꺼지고 이유가 적힙니다. 복원 전 미리보기에서는 프로그램별로 체크를 끄면 그 프로그램은 읽지도 쓰지도 않습니다(체크를 바꾸면 미리보기를 다시 계산합니다).
직접 고른 폴더를 통째로 담고 싶음기본은 직접 고른 폴더에서 설정 파일만 담습니다. 구 PC의 "자동 목록에 없는 프로그램" 화면 고급 옵션에서 폴더 전체 담기를 켜면 설정 파일이 아닌 파일도 담습니다(명령줄의 --extra-mode all). 용량과 시간이 크게 늘고 민감한 정보가 섞일 수 있어 켤 때 한 번 더 확인합니다.
