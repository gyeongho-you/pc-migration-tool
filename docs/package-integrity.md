# 설정 패키지 무결성 안내

## 도구가 확인해 주는 것
설정 패키지(.zip)에는 파일별 SHA-256 과 크기를 적은 `manifest.json` 이 들어 있습니다. 가져오기(import) 전에 도구가 zip 안의 실제 파일과 이 목록을 대조해서, 전송 중 일부가 깨졌거나 잘린 **우연한 손상**을 찾아냅니다.

## 한계: 악의적 변조는 잡지 못합니다
`manifest.json` 이 같은 zip 안에 들어 있으므로, 누군가 의도적으로 파일을 바꾸고 목록의 해시도 함께 고쳐 다시 압축하면 도구는 정상으로 봅니다. 서명이나 암호화는 하지 않습니다(전용 서명 기능 없음). 즉 이 검사는 "만든 그대로인가"가 아니라 "내부 목록과 내용이 서로 맞는가"만 확인합니다.

## 사용자가 할 일
1. **만든 직후 별도 경로로 해시를 기록합니다.** 패키지를 만든 PC 에서 PowerShell 로:

   ```
   Get-FileHash -Algorithm SHA256 .\패키지.zip
   ```

   나온 값을 zip 과 다른 곳(메모, 메신저, 종이 등)에 적어 둡니다. zip 옆에 같이 두면 같이 바뀔 수 있습니다.
2. **받은 PC 에서 같은 명령으로 값을 구해 대조합니다.** 한 글자라도 다르면 가져오지 마세요.
3. **USB/외장 드라이브로 옮길 때**: 꽂은 채로 바로 쓰지 말고 새 PC 로 복사한 뒤 위 대조를 하세요. 직접 건네받는 경우에도 해시는 사진/메모 등 다른 경로로 받으면 더 안전합니다.
4. **출처를 확신할 수 없는 패키지**는 복원(`import --yes`) 전에 반드시 미리보기(dry-run, `--yes` 없이 실행)를 먼저 하고, 대상 경로와 덮어쓸 파일 목록이 예상과 같은지 확인합니다. 규칙에 없는 경로, 시작 프로그램/스크립트 같은 실행 파일이 보이면 중단하세요. 신뢰할 수 없는 패키지는 쓰지 않는 것이 가장 안전합니다.

5. **출처를 모르는 설정 묶음은 복원하지 마세요.** 묶음 안에는 프로그램을 다음에 열 때 코드가 실행되는 파일이 있을 수 있습니다: 플러그인/매크로(SketchUp `.rb`, AutoCAD `.lsp .vlx .fas .arx .mnl`, Revit `.addin`, Rhino/Grasshopper `.rhp .gha`, `.node`, `.ahk`, VS Code `.vsix`, Gradle `.gradle`), 셸/편집기/Git 설정(`.bashrc`, `.bash_aliases`, `.vimrc`, `.emacs`, `.inputrc`, `.config\git\config`, `.gitconfig`). 도구는 이런 확장자와 홈 설정 위치를 기본으로 복원 거부 목록에 두고, 규칙이 그 확장자를 명시한 플러그인(SketchUp/AutoCAD/Revit 규칙의 `allow_extensions`)만 복원하며, 허용은 그 확장자를 적은 규칙 경로 아래의 파일에만 적용됩니다(예: AutoCAD `Support` 의 `.lsp` 허용은 `Plotters` 에는 적용되지 않음). 자동 실행 플러그인은 **직접 만든 묶음이거나 신뢰하는 사람에게 직접 받은 묶음에서만** 복원하세요. `.gitconfig` 는 흔히 쓰므로 경고 후 허용하니 복원 전에 내용을 확인하세요.

덮어쓰는 파일은 `.bak` 으로 먼저 보존되고, 가져오기 기록으로 되돌릴 수 있습니다(`undo-import`). 다만 이것이 변조된 패키지를 막아 주지는 않습니다.

## 가져오기 때 항목만 건너뛰는 경우와 패키지 전체를 거부하는 경우(stage68)
- **그 항목만 '복원 안 함'**(나머지는 정상 복원, 결과에 이유가 표시됨): 이 PC 에 없는 환경변수 위치(예: OneDrive 가 없는 PC 의 `%OneDrive%\Documents`, 지정하려면 `pcmigrate --env ONEDRIVE=D:\OneDrive import …`), 이 버전 규칙의 `exclude`/라이선스(`*.lic`)에 걸리는 옛 패키지의 파일(비밀번호 저장소 등), 복원 거부 확장자·위치.
- **패키지 전체 거부**(복원 안 함, `--only/--skip` 으로도 우회 불가): 경로 탈출(zip-slip)·안전하지 않은 이름, 알 수 없는 규칙 id, 규칙에 허용되지 않은 위치/허용 외 루트, 규칙에 선언된 경로 패턴 밖의 파일, 대상이 허용 루트 밖, 같은 대상으로 가는 중복 항목, 해시·크기 불일치. 선언 크기 합이 1 TiB 를 넘는 패키지도 거부합니다.
- 대상 이름 자리에 같은 이름의 **폴더**가 있으면 미리보기부터 '실패(대상에 같은 이름의 폴더가 있음)'로 보이고, 실제 복원에서도 같은 결과입니다(폴더는 지우지 않음).
- 복원이 취소·예외로 **중간에 멈추면** 이미 쓴 파일의 복원 기록(`undo-import` 근거)을 저장하고, 여기까지의 결과 리포트(`--report`)를 남깁니다. 복원한 파일의 수정 시각은 패키지에 담긴 원본 시각(zip 시각, 2초 단위)으로 맞춥니다.
- `programs/*`(registry.json, winget.json, winget-list.txt)의 SHA-256 도 `manifest.json` 의 `programs_sha256` 에 담아 검증합니다. 이 키가 없는 옛 패키지는 기존처럼 읽되 '변조 여부를 확인할 수 없는 옛 형식' 경고를 표시합니다. 손상/변조된 프로그램 목록은 traceback 대신 '프로그램 목록을 읽을 수 없습니다' 로 안내하고, `winget-extract` 는 winget.json 의 스키마와 id 형식을 확인합니다.

## 알려진 한계(stage68)
- 규칙은 신 PC 에 **설치된 버전을 확인하지 않습니다**: 신 PC 에 없는 버전(AutoCAD 2020 등)의 설정 폴더도 만들어질 수 있습니다(규칙 경고에 안내, 쓰지 않는 폴더는 직접 삭제). 설치 목록과 연계한 자동 건너뜀은 규칙·프로그램 이름 형식이 제각각이라 오탐(정상 설정을 건너뜀) 위험이 커서 넣지 않았습니다.
- 복원한 설정 파일 **내용 안의** 구 PC 경로·사용자 이름은 바꾸지 않습니다(치환은 위험). 복원 결과와 체크리스트에 '설정 파일 안에 구 PC 경로가 들어 있을 수 있음' 경고만 표시합니다.
- `install_paths` 만으로 감지하는 규칙(ArchiCAD/SketchUp/Rhino)은 폴더만 남은 PC 나 같은 제조사의 다른 제품만 있는 PC 에서 오탐할 수 있습니다(규칙 notes 에 명시).
- QGIS 규칙은 폴더 단위 제외를 못 해 `python\plugins` 폴더를 빼지 못합니다(.py 는 복원 거부라 껍데기 폴더가 남을 수 있음, 규칙 경고에 안내). 비밀번호가 들어갈 수 있는 `QGIS3.ini` 는 기본으로 복원하지 않습니다.
- 기록 모드 초안은 이름에 `[ ]` 가 든 파일(`*`, `?` 처럼 glob 오인)을 담지 않습니다.
- Firefox 의 저장 비밀번호는 DPAPI 가 아니라 Firefox 자체 키 저장소에 있어 복사해도 쓸 수 없습니다(브라우저 규칙 경고 문구 정정).
- 복원 거부 확장자 표는 정적 목록입니다: 목록 밖 형식(예: 새 스크립트 형식)은 막지 못할 수 있어 출처 확인이 여전히 필요합니다.
