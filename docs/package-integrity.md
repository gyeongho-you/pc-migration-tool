# 설정 패키지 무결성 안내

## 도구가 확인해 주는 것
설정 패키지(.zip)에는 파일별 SHA-256 과 크기를 적은 `manifest.json` 이 들어 있습니다. 가져오기(import) 전에 도구가 zip 안의 실제 파일과 이 목록을 대조해서, 전송 중 일부가 깨졌거나 잘린 **우연한 손상**을 찾아냅니다.

## 한계: 악의적 변조는 잡지 못합니다
`manifest.json` 이 같은 zip 안에 들어 있으므로, 누군가 의도적으로 파일을 바꾸고 목록의 해시도 함께 고쳐 다시 압축하면 도구는 정상으로 봅니다. 서명이나 암호화는 하지 않습니다(전용 서명 기능 없음). 즉 이 검사는 "만든 그대로인가"가 아니라 "내부 목록과 내용이 서로 맞는가"만 확인합니다.

## 사용자가 할 일
1. **만든 직후 별도 경로로 해시를 기록합니다.** 패키지를 만든 PC 에서 PowerShell 로:

   ```
   Get-FileHash -Algorithm SHA256 .\패키지.zip
   ```

   나온 값을 zip 과 다른 곳(메모, 메신저, 종이 등)에 적어 둡니다. zip 옆에 같이 두면 같이 바뀔 수 있습니다.
2. **받은 PC 에서 같은 명령으로 값을 구해 대조합니다.** 한 글자라도 다르면 가져오지 마세요.
3. **USB/외장 드라이브로 옮길 때**: 꽂은 채로 바로 쓰지 말고 새 PC 로 복사한 뒤 위 대조를 하세요. 직접 건네받는 경우에도 해시는 사진/메모 등 다른 경로로 받으면 더 안전합니다.
4. **출처를 확신할 수 없는 패키지**는 복원(`import --yes`) 전에 반드시 미리보기(dry-run, `--yes` 없이 실행)를 먼저 하고, 대상 경로와 덮어쓸 파일 목록이 예상과 같은지 확인합니다. 규칙에 없는 경로, 시작 프로그램/스크립트 같은 실행 파일이 보이면 중단하세요. 신뢰할 수 없는 패키지는 쓰지 않는 것이 가장 안전합니다.

덮어쓰는 파일은 `.bak` 으로 먼저 보존되고, 가져오기 기록으로 되돌릴 수 있습니다(`undo-import`). 다만 이것이 변조된 패키지를 막아 주지는 않습니다.
